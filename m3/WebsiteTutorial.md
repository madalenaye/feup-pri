1. Install django using pip 

```py 
pip install django
```
2 Go to backend folder
3. Create views/request handlers in views.py
4. Add import of the view/request handler in urls.py
5. add endpoint associated with that view/request handler 

6. To run the server:
```py 
python manage.py runserver 5001
```
5001 is the port number you want to initialze the server at


7. Go to frontend folder/pokemon_the_series
8. Install the necessary dependencies:
```py 
npm install
```
9. To run the frontend website:
```py 
npm start

```
